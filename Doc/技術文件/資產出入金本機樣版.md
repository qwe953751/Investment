# 資產出入金：正式整合與本機驗證

## 決策與架構

2026-11-04 使用者確認最終樣版，授權正式整合、更新文件、commit／push 與網站發布，並明確選擇「C# 產生計算模組」。正式程式與 Supabase migration 已完成，發布驗收見[版本紀錄](../版本紀錄.md)。

GitHub Pages 沒有常駐 C# 後端，因此由 AssetPerformanceFormulas.cs 的同一份 expression 產生瀏覽器金融運算與換匯 SQL；C# calculator 編譯同一 expression。相較新增後端或手寫第二套公式，此方式保留既有部署並能測試一致性。exporter 將產生模組、原 site.js、asset-performance-ui.js 合併到同一版本檔案，正式 UI 不依賴 loopback 端點或私有帳本，沒有新增套件。

## 最終版面與公式

第一排左側「資產變化／當年損益變化」，右側「考慮出入金／十字線」；第二排標題與選點日期／金額／比較資料。總覽與帳戶同步，沿用正式 CSS 與換行；site.css 未修改。出入金預設開啟，與十字線使用相同 enabled 藍色及 aria-pressed；關閉標題不加「含出入金」。不顯示本機唯讀／資料筆數列。

| 項目 | 出入金開啟 | 出入金關閉 |
|---|---|---|
| 資產變化 | 可見期初資產＋期間投資損益 | 實際資產總值 |
| 當年損益變化 | 當日資產－去年底資產－當年截至該日淨入金 | 當日資產－去年底資產 |
| 年度／月份報酬 | 投資損益 ÷（期初資產＋加權淨入金） | 資產增減 ÷ 期初資產 |

Modified Dietz 加權為每筆帶方向金流乘以該日到期末剩餘天數占整段天數比例；區間為 (期初日, 期末日]。這是估算報酬，非年化、TWR 或 XIRR；卡片顯示「今年報酬（估算）」或「今年資產增減率」。月份使用前一月底快照，缺基準顯示「—」。

當年曲線的期間按鈕只篩日期，不重設去年底基準；總覽須每個帳戶前一年估值完整，缺年不借其他年。期初零且無入金無法分辨投入與獲利，基準資金不大於零不提供百分比。缺必要匯率或金流不顯示部分合計。

「入金成本」為累計淨入金、中性色；年度淨投入為該曆年金流。帳戶表「總獲利」固定為目前資產減累計入金成本，不受期間或開關影響。NT 金額僅在格式化時取絕對值，不顯示正負號；百分比保留正負號，紅綠色及圖表座標使用原始數值，USD 符號不變。未實現損益只一組百分比。

## 美元匯率與正式保存

正式 Supabase 已套用 db/075_asset_cash_flow_fx_snapshots.sql，沿用既有表 RLS／角色權限。保存 currency、fx_rate、fx_date、fx_source、fx_captured_at、fx_history；amount_twd 為 round(amount * fx_rate, 2) generated 欄位，測試核對與 C# 產生的表示式一致。更正金額、日期、方向或帳戶保留舊版；只改備註不重估，傳入新匯率也不能改寫已完成值。

USD 採金流日期以前最近可得官方匯率，TWD 為 1；缺匯率留空、來源補齊後只估一次，未來日不借目前值。歷史參考估值不代表券商實際換匯成本。現有年度資產快照不重建，美元現值仍按資料庫最新匯率換算，保留台幣投資人的匯率變化。出入金表顯示幣別／採用匯率／匯率日期／估算台幣金額，不顯示換算依據欄。

期交所歷史頁已核對並只補缺值：2025/05/05 為 30.145、2026/11/03 為 32.760；既有日期未覆寫。repo 根目錄以 .NET 10 執行：

```powershell
dotnet run --project src/Invest.Web -c Release --no-launch-profile -- sync-fx --date 2025-05-05
```

歷史模式查指定日前七日內最近有效值，只補缺值；無參數 sync-fx 維持每日流程。失敗提供錯誤類型與 SQLSTATE，勿提供連線字串或密碼。這台 Windows 原直接連線不可用、pooler 回 28P01；本次已授權的 DDL 與精確匯率補入使用既有 Supabase 管理通道，沒有更換憑證或放寬權限。

## 本機唯讀驗證

repo 根目錄以 .NET 10 執行：

```powershell
dotnet run --project src/Invest.Web -c Release --no-launch-profile -- asset-preview
```

開啟 http://127.0.0.1:5263/?access=admin&view=assets ，預期正式 HTML／CSS 及本次正式 JS 讀取現有全部資產、年度、快照、金流與匯率。僅綁 loopback；外部非 GET／HEAD、快照保存與 OCR 恢復停用。同源 /preview/calculate、/preview/value-flows 只保留 C# 對照及本機帳本入口，正式 UI 不依賴它們。私有帳本、個人金額與截圖位於忽略的 artifacts／publish，不提交或透過 HTTP 提供。無資料或無網路保留錯誤，不補示意數據。
