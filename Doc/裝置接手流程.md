# 裝置接手流程

這份文件給**新裝置、手機、公司電腦（CodeX）或任何 AI agent** 接手這個專案時用：
從零開始要先做哪幾件事、順序是什麼。日常開發環境細節（要裝什麼套件、環境變數、
憑證）請看 [開發環境.md](開發環境.md)；這裡只列「接手當下」該做的步驟。

1. 先切到最新主線並確認 commit：

   ```bash
   git switch main
   git pull --ff-only origin main
   git log -1 --oneline
   ```

   預期至少包含功能提交 `82630d7`；若後續只更新文件，最新 commit 可能會比它更新。

2. 先讀這幾份文件：

   - [README.md](../README.md)：功能、公式與日常指令。
   - [完成進度.md](完成進度.md)：目前已完成項目與踩過的坑。
   - [開發環境.md](開發環境.md)：.NET 10、PATH、權限與本機預覽。
   - [TODO.md](../TODO.md)：尚未開始或仍在討論的工作。

3. Windows 先確認 .NET 10：

   ```powershell
   & "$env:LOCALAPPDATA\Microsoft\dotnet\dotnet.exe" --version
   ```

   預期為 `10.0.302`。若 `dotnet` 命令仍指向 .NET 8，使用上面的絕對路徑；不要以 .NET 8 建置本專案。

4. 修改程式碼前，確認 `db/008_intraday_kline.sql` 已存在；若是新資料庫或新環境，依 README 的 migration 順序套用，不能用假資料跳過。

5. 修改畫面或計算後，先跑測試，再重新 export；正式網站使用 `gh-pages` 快照，不會自動讀取 `main` 的原始碼。
